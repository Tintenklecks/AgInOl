어디서든 Mac의 AI 코딩 에이전트가 작업 중인지, 입력을 기다리는지 확인하세요.

중요: AgInOl Companion은 단독 모니터가 아닙니다. 먼저 https://aiia.li/apps/aginol에서 AgInOl for Mac을 다운로드하고 에이전트가 실행되는 Mac에 설치한 뒤 앱을 계속 실행해 두세요. Mac과 iPhone 또는 iPad는 iCloud가 활성화된 동일한 Apple Account를 사용해야 합니다.

Mac 바로 옆이든 500km 떨어진 곳이든 최신 덱 스냅샷을 읽기 전용으로 볼 수 있습니다. 두 기기가 같은 Wi-Fi 네트워크에 연결될 필요는 없습니다.

한눈에 보기
• 작업 중, 유휴 상태, 입력 필요, 찾을 수 없음 상태
• 열린 세션, 프로젝트 이름, 모델, 경과 시간
• 사용 가능한 토큰과 사용 한도 및 제공되는 경우 초기화 시각
• 모든 에이전트 요약
• 스냅샷 경과 시간과 오래된 데이터 표시

작동 방식
AgInOl for Mac은 지원되는 코딩 도구의 로컬 세션 파일을 읽고 축약된 상태 스냅샷을 iCloud로 전송합니다. Companion 앱은 에이전트를 실행하거나 제어하지 않습니다.

최신 업데이트를 받으려면 Mac 앱을 실행하고 Mac을 온라인 상태로 유지하세요. iCloud 반영에는 몇 초에서 몇 분이 걸릴 수 있습니다. Claude Code, Codex, OpenCode, Kimi Code를 지원합니다.
