현재 창을 벗어나지 않고 어떤 AI 코딩 에이전트가 작업 중인지, 입력을 기다리는지 확인하세요.

AgInOl은 공증된 Mac 메뉴 막대 앱이며 다음 주소에서 직접 배포됩니다.
https://aiia.li/download/aginol.zip

플로팅 덱은 다른 창 위에 유지되지만 터미널의 키보드 포커스를 가져가지 않습니다. 여러 에이전트의 상태를 한눈에 파악할 수 있습니다.

하나의 덱에서 모두 확인
• Claude Code, Codex, OpenCode, Kimi Code 모니터링
• 작업 중, 입력 필요, 유휴, 찾을 수 없음 상태 구분
• 열린 세션, 프로젝트 이름, 모델, 경과 시간
• 토큰, 플랜 한도, 비용, 제공되는 경우 초기화 시각
• 입력이 필요한 에이전트를 확인 처리

원하는 대로 구성
• 2 × 1부터 6 × 4까지 그리드 선택
• 상태, 사용량, 요약, 시계, 정보 페이지를 각 키에 배치
• 추가 정보를 순환 표시하는 정보 막대
• 패널을 화면 가장자리에 숨기고 클릭 한 번으로 복귀

로컬 데이터와 명확한 네트워크 제어
AgInOl은 지원되는 도구가 Mac에 저장한 세션 파일을 읽습니다. 서비스 제공업체의 온라인 사용량 조회는 기본적으로 꺼져 있습니다. Companion용 읽기 전용 덱 스냅샷은 iCloud로 계속 동기화됩니다.

iPhone 또는 iPad에서 확인
AgInOl Companion을 사용하면 수백km 밖에서도 작업 및 입력 대기 상태를 볼 수 있습니다. 두 기기에서 동일한 Apple 계정과 iCloud를 사용해야 하며, 최신 업데이트를 위해 Mac 앱을 실행하고 Mac을 온라인 상태로 유지해야 합니다.
